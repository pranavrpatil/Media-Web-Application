Media SDK

Documentation

A TypeScript ecosystem for consuming Pexels media through a framework-agnostic client, with React and React Native adapters.

Architecture

  • @media/core contains the Pexels client, typed media contracts, caching, request de-duplication, errors, and events.
  • @media/react provides MediaProvider and React hooks.
  • @media/native provides the React Native adapter.
  • @media/ui-react is an independent headless UI package.

Installation

npm install @media/core
npm install @media/react react
npm install @media/native react react-native

Authentication

Create a client with a Pexels API key. Never commit the key to source control.

import { createMediaClient } from "@media/core";

const mediaClient = createMediaClient({
  apiKey: "YOUR_PEXELS_API_KEY",
});

Photo APIs

const searchPage = await mediaClient.photos.search({
  query: "mountains",
  page: 1,
  perPage: 20,
  orientation: "landscape",
});

const curatedPage = await mediaClient.photos.curated({
  page: 1,
  perPage: 20,
});

const photo = await mediaClient.photos.getById(123);

Video APIs

const videoPage = await mediaClient.videos.search({
  query: "ocean",
  page: 1,
  perPage: 15,
  orientation: "landscape",
});

const video = await mediaClient.videos.getById(456);

Errors

SDK-generated failures use MediaSdkError where possible.

Code Meaning
INVALID_CONFIGURATION Blank API key or no runtime fetch implementation.
INVALID_REQUEST A photo or video search query is blank.
HTTP_ERROR Pexels returned a non-2xx response.
NETWORK_ERROR The fetch operation failed before a response was received.
INVALID_RESPONSE The response body was not valid JSON.
