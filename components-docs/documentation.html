Introduction

@media/ui-react and @media/ui-native are headless media UI libraries. They own interaction behavior, component state, event handling, scrolling, active-item detection, and the accessibility attributes implemented by the source. The consumer owns data fetching, application state, markup inside render callbacks, CSS or StyleSheet, layout, colors, typography, spacing, and responsive behavior.

The components accept the generic MediaItem contract: id, src, and alt are required; type, thumbnailSrc, dimensions, and duration are optional.

Architecture

media-core
  +--> media-react --> React application --> media-ui-react
  |
  +--> media-native --> React Native application --> media-ui-native

The UI packages are independent. They do not import @media/core, @media/react, @media/native, or Pexels code. An application maps any source into the UI item contract and connects callbacks to its own state.

Installation

npm install @media/ui-react react
npm install @media/ui-native react react-native

These packages are private workspace packages in this repository. Build them with npm run build --workspace @media/ui-react and npm run build --workspace @media/ui-native.

React

Grid

Grid renders a semantic grid wrapper and delegates each item to renderItem. It supports keyboard navigation, item callbacks, and an optional IntersectionObserver load-more trigger. It never performs the request itself.

import { Grid, type MediaItem } from "@media/ui-react";

const items: MediaItem[] = [
    { id: "1", src: "/mountain.jpg", alt: "A mountain lake", type: "image" },
];

<Grid
    items={items}
    columnCount={4}
    ariaLabel="Search results"
    onItemClick={(item, index) => setSelectedIndex(index)}
    renderItem={({ item, getItemProps }) => (
        <article {...getItemProps()}>
            <img src={item.src} alt={item.alt} />
        </article>
    )}
/>
Prop Type Required Description
items readonly T[] Yes Items extending MediaItem.
renderItem (context) => ReactNode Yes Renders an item using item, index, and getItemProps().
getItemKey (item, index) => Key No Defaults to item.id.
getItemProps (item, index) => HTMLAttributes No Consumer props merged before generated grid behavior.
ariaLabel string No Grid label; defaults to Media grid.
columnCount number No Arrow up/down focus step; it does not create CSS columns.
onItemClick, onItemFocus (item, index) => void No Called after the corresponding interaction.
onLoadMore () => void | Promise<void> No Called when the load-more sentinel intersects.
hasMore, loadingMore boolean No Enable the sentinel and prevent observation while loading.
renderLoadMoreTrigger (props) => ReactNode No Custom sentinel. Receives ref and aria-busy.

Grid keyboard behavior is Enter/Space to activate, arrow keys to move, and Home/End to reach the first/last item. With hasMore, the observer calls onLoadMore; the application should append items and manage loadingMore.

Lightbox

Lightbox is controlled by open and item. It returns null when closed or when there is no item. The default renderer displays an img or a video controls element based on item.type; use renderMedia for custom media.

<Lightbox
    open={selected !== null}
    item={selected}
    items={items}
    index={selectedIndex}
    onClose={() => setSelectedIndex(null)}
    onPrevious={() => setSelectedIndex((value) => Math.max(0, value - 1))}
    onNext={() => setSelectedIndex((value) => Math.min(items.length - 1, value + 1))}
    renderMedia={({ item, getMediaProps }) => (
        item.type === "video"
            ? <video {...getMediaProps()} src={item.src} controls />
            : <img {...getMediaProps()} src={item.src} alt={item.alt} />
    )}
/>
Prop Type Required Description
open, item, onClose boolean, T | null, () => void Yes Controlled visibility, selected media, and close callback.
items, index readonly T[], number No Navigation collection and current index. Index defaults to 0.
onNext, onPrevious () => void No Enable corresponding controls when supplied and in range.
loop boolean No Allows navigation at collection boundaries; the app still changes the item.
closeOnEscape, closeOnBackdropClick boolean No Both default to true.
renderMedia, button render props Render callbacks No Customize media, close, previous, and next controls.

When opened, focus moves to the close button. On close, focus returns to the previously focused element. Escape closes by default; Left/Right call navigation callbacks when available. The dialog has role="dialog", aria-modal="true", and a configurable label.

ReelSwiper

ReelSwiper renders a region with carousel semantics and one slide per item. It supports controlled activeIndex or an initial defaultActiveIndex. IntersectionObserver detects the slide that is at least 60% visible; keyboard navigation is enabled by default.

<ReelSwiper
    items={videos}
    ariaLabel="Video reels"
    activeIndex={activeIndex}
    onActiveItemChange={(item, index) => setActiveIndex(index)}
    renderSlide={({ item, isActive, getSlideProps }) => (
        <article {...getSlideProps()}>
            <video src={item.src} controls playsInline autoPlay={isActive} />
            <p>{item.alt}</p>
        </article>
    )}
/>
Prop Type Required Description
items, renderSlide readonly T[], (context) => ReactNode Yes Slides and custom slide rendering.
activeIndex number No Controlled active index.
defaultActiveIndex number No Initial uncontrolled index; defaults to 0.
onActiveItemChange (item, index) => void No Called on keyboard selection or visibility changes.
getItemKey, ariaLabel (item, index) => Key, string No Key defaults to item.id; label defaults to Media reel.
loop, keyboardNavigation boolean No Both default to true only for keyboard navigation; loop defaults to false.

The component does not play, pause, or fetch video itself. Use isActive to decide how your renderer handles a video. The consumer must give the viewport/slides dimensions and scrolling CSS.

React Native

Import the native package from @media/ui-native. Its item contract is the same, but props use React Native types and names.

Grid

Native Grid wraps FlatList, passes numColumns, and uses onEndReachedThreshold={0.7}. When hasMore is true and loadingMore is false, it wires onLoadMore to onEndReached.

import { Grid } from "@media/ui-native";

<Grid
    items={items}
    numColumns={2}
    onItemPress={(item, index) => setSelected(item)}
    onLoadMore={() => loadNextPage()}
    hasMore={hasMore}
    loadingMore={loading}
    renderItem={({ item, getItemProps }) => (
        <Pressable {...getItemProps()}>
            <Image source={{ uri: item.src }} accessibilityLabel={item.alt} />
        </Pressable>
    )}
/>

Props are items, renderItem, getItemKey, getItemProps, accessibilityLabel, numColumns, onItemPress, onItemFocus, onLoadMore, hasMore, and loadingMore. The render context provides item, index, and getItemProps(), which returns PressableProps with accessible grid-cell behavior.

Lightbox

Native Lightbox is controlled by visible and item. It uses React Native Modal and closes through onClose or the Android hardware back button. The default renderer is an Image; video requires a custom renderMedia implementation such as a video component from your application.

import { Lightbox } from "@media/ui-native";

<Lightbox
    visible={selected !== null}
    item={selected}
    items={items}
    index={selectedIndex}
    onClose={() => setSelected(null)}
    renderMedia={({ item, getMediaProps }) => (
        <Image {...getMediaProps()} source={{ uri: item.src }} />
    )}
/>

Native props are visible, item, optional items/index, accessibilityLabel, onClose, optional onNext/onPrevious, loop, renderMedia, and the three button render callbacks. The library supplies dialog and button accessibility labels. It does not implement focus restoration or a keyboard Escape interaction.

ReelSwiper

Native ReelSwiper wraps a vertical, paging-enabled FlatList. It uses a 60% item-visible threshold to detect the active item and calls onActiveItemChange(item, index). It accepts items, renderSlide, optional controlled/initial indices, onActiveItemChange, getItemKey, and accessibilityLabel.

<ReelSwiper
    items={videos}
    accessibilityLabel="Video reels"
    onActiveItemChange={(item, index) => setActiveIndex(index)}
    renderSlide={({ item, isActive, getSlideProps }) => (
        <View {...getSlideProps()}>
            <Video source={{ uri: item.src }} paused={!isActive} />
        </View>
    )}
/>

The render context supplies item, index, isActive, and getSlideProps(). The package does not include a video player and does not expose a native loop or keyboard-navigation prop.

Headless API and prop getters

A prop getter is a render-context function that returns the platform props needed for the behavior owned by the component. Spread it onto the interactive element you render, then add your own class names, styles, and content.

renderItem={({ item, getItemProps }) => (
    <button {...getItemProps()} className="tile" type="button">
        <img src={item.src} alt={item.alt} />
    </button>
)}

renderSlide={({ getSlideProps, item }) => (
    <article {...getSlideProps()}>{item.alt}</article>
)}

React Grid's generated props include role="gridcell", tabIndex, click/focus/key handlers, and arrow/Home/End behavior. React Lightbox's getMediaProps() supplies an aria-label. React ReelSwiper's getSlideProps() supplies active/inactive tab order. Native getters supply the corresponding PressableProps, ViewProps, or accessibility state. Consumer handlers are invoked before the library callback where both are composed.

Styling

No application CSS is shipped. For React, the component controls structure and behavior; the consumer sets the grid layout and media dimensions:

.results-grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px; }
.tile img { display: block; width: 100%; aspect-ratio: 1; object-fit: cover; }
.reel-viewport { height: 80vh; overflow-y: auto; scroll-snap-type: y mandatory; }
.reel-slide { min-height: 80vh; scroll-snap-align: start; }

In React Native, pass styles to the elements you render or use StyleSheet.create. The native Grid owns the FlatList; the item render callback owns the tile appearance and dimensions.

const styles = StyleSheet.create({
    tile: { flex: 1, aspectRatio: 1, margin: 4 },
    media: { width: "100%", height: "100%" },
});

Accessibility

Library responsibilities: React Grid emits a grid and grid-cell semantics, keyboard movement, and focus handling. React Lightbox emits dialog semantics, modal state, labels, close-button focus, Escape handling, and focus return. React ReelSwiper emits region/carousel/slide semantics and active slide state. Native components emit the accessibility roles, labels, selected state, and modal/back-button behavior visible in their source.

Consumer responsibilities: provide meaningful alt/accessibilityLabel values, keep custom controls visibly labeled, spread the getter props onto the intended element, provide usable dimensions and focusable controls, and ensure custom media players expose their own controls. The packages do not claim WCAG compliance and do not provide a focus trap, native video player, or automatic styling.

Data-agnostic usage

The UI library does not care whether items come from Pexels, another REST or GraphQL API, local JSON, a database, another SDK, or generated data.

import { Grid, type MediaItem } from "@media/ui-react";

const media: MediaItem[] = [
    { id: "1", type: "image", src: "/example.jpg", alt: "Example image" },
];

<Grid
    items={media}
    renderItem={({ item, getItemProps }) => (
        <button {...getItemProps()} type="button">
            <img src={item.src} alt={item.alt} />
        </button>
    )}
/>

SDK + UI integration

The application is the boundary between data and UI. @media/react handles the SDK client and search state; @media/ui-react only receives mapped items.

import { MediaProvider, useMediaSearch } from "@media/react";
import { Grid, type MediaItem } from "@media/ui-react";
import { client } from "./media-client";

function Results() {
    const search = useMediaSearch({ type: "photo", query: "mountains", page: 1 });
    const items: MediaItem[] = search.results.map((photo) => ({
        id: photo.id,
        src: photo.src.medium,
        thumbnailSrc: photo.src.small,
        alt: photo.alt || `Photo by ${photo.photographer}`,
        width: photo.width,
        height: photo.height,
    }));

    return <Grid
        items={items}
        hasMore={search.hasMore}
        loadingMore={search.loading}
        onLoadMore={search.loadMore}
        renderItem={({ item, getItemProps }) => (
            <article {...getItemProps()}>
                <img src={item.thumbnailSrc ?? item.src} alt={item.alt} />
            </article>
        )}
    />;
}

<MediaProvider client={client}><Results /></MediaProvider>

For videos, map a Pexels video_file.link to src, the Pexels image to thumbnailSrc, and set type: "video". The component package remains unaware of that mapping.

API reference overview

Package Exports Behavior surface
@media/ui-react Grid, Lightbox, ReelSwiper, related props/context/types DOM attributes, keyboard handling, IntersectionObserver, focus behavior, render callbacks
@media/ui-native Grid, Lightbox, ReelSwiper, related props/context/types FlatList, Modal, Pressable/View props, viewability, hardware back handling

There are no public UI hooks in either package. The complete public type names are MediaId, MediaItem, GridProps, GridItemRenderContext, LightboxProps, LightboxRenderContext, ReelSwiperProps, and ReelSlideRenderContext. React uses DOM attribute types; native uses React Native PressableProps and ViewProps.

Troubleshooting

  • Nothing appears: pass a non-empty items array and return visible markup from the render callback.
  • Load more does not run: set hasMore, pass onLoadMore, and clear loadingMore after appending results. The web sentinel also needs room to intersect.
  • Keyboard movement is wrong: React Grid uses columnCount only as the vertical focus step; CSS still defines the visual layout.
  • Reel video does not play: use isActive in your renderer. The library does not own a video player.
  • Native video is missing: supply a custom renderMedia or renderSlide; the native Lightbox default is an Image.
  • API errors: keep fetching and authentication in @media/core/@media/react; the UI packages accept already-mapped data only.
