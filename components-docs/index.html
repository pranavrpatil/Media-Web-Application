Media UI

Headless media components.

Interaction primitives for media grids, viewers, and vertical reels in React and React Native. Your application owns the data and visual design.

Read component documentation Read SDK documentation

What is included

  • @media/ui-react: generic React Grid, Lightbox, and ReelSwiper.
  • @media/ui-native: React Native versions of the same three components.

Headless by design

Components receive an array of items, render callbacks, and event callbacks. They do not fetch from Pexels, authenticate, import the SDK, or ship application CSS. The render contexts expose the accessibility and interaction props that consumers spread onto their own elements.

Start with the data-agnostic example, then see the SDK integration section for the application composition.
