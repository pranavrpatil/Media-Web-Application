# Skills

The two agent skills used while building the web integration are:

- [`data-wiring/SKILL.md`](data-wiring/SKILL.md) - provider setup, hooks, authentication, pagination, and events.
- [`component-usage/SKILL.md`](component-usage/SKILL.md) - headless prop-getters, styling, accessibility, Grid, Lightbox, and ReelSwiper usage.

They are intentionally specific to this repository so an AI coding assistant can
produce code that preserves the dependency boundaries and component contracts.
